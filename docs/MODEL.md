# Frozen finite-element contract v1.0.0

The authoritative inputs are `benchmarks/10bar.json`, `benchmarks/25bar.json` and `benchmarks/LOCK.sha256.json`. Node and member numbers are one based; group indices and displacement directions are zero based. Nodes, candidate members, support translations, prescribed load vectors, material, size catalogue, groups, tolerances and section law are fixed. Crossings are not joints unless a node is explicitly shared. Fixed nodes have every translation restrained. No rotational degrees of freedom exist.

For each member, length L and unit vector n are derived from the undeformed geometry. Extension is n·(u_j-u_i), axial force N=EA/L times extension (positive tension), and stress N/A. Solve the restrained system K_ff u_f=f_f. Reactions are K u-f. Every original node must connect to a support; the free stiffness must be positive definite with lambda_min/lambda_max > 1e-12. A connected graph alone is insufficient. Removed members have exactly zero area and stiffness, never an artificial weak stiffness.

The objective is mass = sum(rho A L), with rho=0.1 lbm/in^3 and kg=lbm×0.45359237. Papers often label this numeric quantity “weight (lb)”; loads here are lbf and no self-weight load is added. Unit conversions in prose sources sometimes differ: the imperial inputs, not rounded SI equivalents, define this pilot.

**Reference profile:** reproduce the source stress/displacement problem. All groups remain present; no buckling criterion exists in this historical profile. Passing it alone says nothing about buckling resistance. The 10-bar problem limits all free translations to 2 inches. The 25-bar problem limits only top-node X/Y translations to 0.35 inches; all other displacements are still calculated and reported. Each source case has one simultaneous nodal load vector, not separate load cases for each applied force.

**tube-euler profile (pilot extension):** the same geometry, loads, catalogue and groups, with optional group deletion and an ideal circular annulus, inner/outer diameter ratio r=0.9. Thus D=sqrt(4A/[pi(1-r²)]), I=pi[D⁴-(rD)⁴]/64. Compressive force must satisfy -N <= pi² E I/[(k L)² × 1.5], k=1.0. The Euler factor 1.5 is a research assumption, not a design-code safety factor. All-largest designs are feasible starting points. A sizing-only search under this identical profile forms an ablation; the topology search additionally admits zero. Geometry and available nonzero sections never change.

Floating point constraints allow relative utilization 1+1e-8, free equilibrium residual <=1e-9 relative to maximum applied force, and solver agreement <=1e-8 with an absolute scale floor of one in the relevant units. The independent checker also tests global force and moment balance and strain energy/work equality at 1e-9. Reported utilizations are unreduced ratios, so margins can be inspected. These are numerical acceptance tolerances, not physical uncertainty allowances.

The primary solver uses a compatibility matrix and SciPy Cholesky. The second independently coded solver builds every element stiffness block, solves using pure-Python Gaussian elimination with partial pivoting, and derives section inertia from diameters. It shares only input data and the stated model, not assembly/solve/check code. Both implementations were authored in this session; this is implementation diversity, not independent human review or an external engineering package validation.

Excluded: self-weight loading, imperfections, geometric/material nonlinearity, global nonlinear buckling, residual stress, connection flexibility/strength, local tube buckling, fatigue, vibration, accidental loads, corrosion, fabrication tolerances, foundations and construction sequences. The planar case assumes ideal planar motion and omits out-of-plane instability. The tube sections are mathematical sections, not verified purchasable products. These are model-validated research designs, never physically certified construction designs.
